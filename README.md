# シーザー暗号・ヴィジュネル暗号 ホイール解読ゲーム

ドラッグで回転するSVGホイールを使ってシーザー暗号とヴィジュネル暗号を視覚的に学べるインタラクティブアプリ。

## 機能

- **シーザー暗号ホイール**: SVGで描画した回転ホイール（マウス/タッチドラッグ対応）で暗号化・復号化を視覚的に操作
- **総当たり解析**: 25通り全シフトパターンを一覧表示して暗号文を解読
- **ヴィジュネル暗号**: タブラ・レクタ（26×26グリッド）をハイライト付きで表示し、キーと平文の対応を視覚化
- **解読パズル**: 10問のシーザー/ヴィジュネル混合パズル（頻度分析チャート・ヒント機能付き）
- ハイスコアをlocalStorageに保存
